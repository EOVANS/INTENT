# 孤岛笔记：实现与交接

开始日期：2026-10-27（Asia/Hong_Kong）。范围来自用户的 Local Highlights & Notes 需求，延续少依赖、少代码的实现方式。

## 首版范围

- 阅读器长按正文段落，保存高亮并可添加备注；点击已有高亮进行修改或删除。
- 底部“笔记”进入全部笔记，文章页进入本篇笔记；支持查看、修改、删除与 Markdown 导出。
- 不要求 BYOK，不联网处理笔记。信息饮食报告和 AI 分析留待单独实现。
- 每条笔记保存文章标题、来源、链接、摘录、备注和创建/修改时间，文章过期清理或删除订阅后仍保留。

## 存储与定位

- `noBackupFilesDir/island-notes/<UTC 年月>/<UUID>.md`，本地 Markdown 是唯一持久化来源，不新增数据库表或依赖。
- Markdown 注释头保存定位元数据，正文以引用块保存摘录、以普通 Markdown 保存备注。使用同目录临时文件、原子替换和协程互斥锁避免半写入与并发重复保存；读取仍兼容旧 AtomicFile 文件。
- 段落按原文文本及相同文本的出现次序定位，避免中文视觉排版插入字符影响摘录；正文变动后只匹配仍相同的段落。
- 普通缓存清理不删除笔记；系统云备份不包含笔记。用户主动导出时通过系统文件选择器保存 `.md`，应选择本机目录。卸载或系统“清除数据”仍会移除未导出的笔记。
- 坏文件保留并提示，其他正常笔记继续可读；不把读取失败误当成用户删除。

## 2026-10-29 同篇文章合并

- 笔记首页按 articleId 合并同一文章的多个摘录，搜索也会查找该文章的各段备注；本周数量按文章计数。打开卡片或阅读器的书签按钮进入同一文章的完整笔记。
- 详情显示标题、原文段落和对应的灰色备注，点某段可继续修改或删除该段；底部显示最近编辑时间和字数（摘录及备注中的 Unicode 字符，不计空白）。
- 若原文仍存在，按原文段落顺序排列；原文已变更或清理时，无法匹配的段落仍保留，并按创建时间排列。现有每段独立的 Markdown 文件继续作为本地存储，无迁移或新依赖；导出时按文章组合成完整 Markdown 文档。
