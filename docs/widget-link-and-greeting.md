# 每日欢迎表情和桌面组件跳转

2026-10-28：按用户要求，首页改为 Hi、欢迎及表情、用户名分行显示。表情从指定十项中首次进入时随机选择，以本地日期和表情保存在设置 DataStore；同日重启和普通缓存清理不重选，下一次打开跨天时重选且避免与前一天相同。主界面仍可跨语言使用。

组件跳转排查：原流程在异步查询文章前清除了启动参数，导致 Compose LaunchedEffect 因 key 变化取消查询；现在查询及导航完成后才消费参数，并保留取消语义。每篇文章的显式 Intent 增加携带 ID 的独立 data URI，避免 Android PendingIntent 仅按 extras 区分失败。不存在的文章不会发生跳转。

回归测试覆盖跨天重选、并发同日只选一次、重新创建与普通缓存清理后的稳定性，以及不同文章 Intent 的身份隔离。编码后的导航路径也支持特殊字符文章 ID。

验证记录：125 项单元测试通过，编译和 lint 通过；真机先后点击组件两篇不同文章，均打开对应标题，最终版再次点击也正确。跨过本地午夜时表情更新，同日重新安装打开仍保持一致。尝试使用 `am kill` 结束后台进程，但应用进程仍在，因此不能将该次点击作为冷进程验证。阅读页滚动后四个顶部按钮保持原位置，渐变遮罩的实际效果已经检查。
