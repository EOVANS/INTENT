# 桌面组件图片与退出清理冲突

排查日期：2026-10-26；修复验证更新：2026-10-27（Asia/Hong_Kong）。用户报告桌面组件无图片，要求判断网络问题。

## 真机证据

- 已放置小尺寸图片样式组件，8 篇文章中 6 篇有图片，当前文章有 `images.macrumors.com` 的图片地址。
- 普通设置的 `clear_cache_on_exit=true`，仅 Wi-Fi 图片开关未开启。
- `cache/image_cache` 只剩 journal，没有实际图片文件；桌面 RemoteViews 的 bitmap memory 为 0。
- 组件的所有 Coil 请求明确禁止网络，只有 RSS 同步 Worker 预取图片。因此退出清理会删除组件唯一依赖的图片数据，重新渲染时只显示占位背景。这是已确认的设置与缓存交互问题，不能据此保证每个远端图片地址都可访问。
- 另一个刷新缺口：图片映射在 `provideGlance` 开始时被捕获。活跃 Glance 会话只更新状态/内容，下载完成后不一定重新加载位图。

## 修复

- 保留用户的退出清理选择，不用关闭清理来掩盖问题。
- 在 `noBackupFilesDir/widget-artwork` 保存组件的小尺寸图片快照，最大边 640 像素，按 URL 哈希命名，不进入系统云备份。普通缓存清理不删除这些展示快照。
- 同步预取成功和组件从已有 Coil 缓存读图时更新快照；缓存缺失时离线读取快照。组件仍不自行联网。
- 同步结束后只保留当前组件文章及来源 logo 对应的快照，淘汰过期图片。
- 组件状态增加 artworkRevision，组合中的 produceState 依据文章和 revision 重新加载图片，修复活跃会话空图映射不刷新的问题。

## 验证结果

- 4 项组件回归测试通过：普通缓存清理后快照仍可读，Coil 缓存为空时组件可离线读图，尺寸受限、缩略图不覆盖大图、旧图片淘汰及 URL 隔离。
- 完整单元测试 113 项通过，0 失败、0 跳过。Coil 的测试需推进 Robolectric 暂停的主线程 looper，避免生命周期调度等待。
- APK 编译和 `lintDebug` 通过，修复版输出为工作区根目录 `INTENT-1.2.apk`，版本仍为 1.2（versionCode 4）。
- 2026-10-27 手机重新连接并解锁后，已通过 `adb install -r` 覆盖安装修复版，订阅和配置保留。在首页下拉同步后，`no_backup/widget-artwork` 保存了当前 8 篇文章的配图，合计约 1.36 MB，旧快照已淘汰。
- 在设置中执行“一键清理缓存”，普通 `cache/image_cache` 只剩 journal，组件快照仍为 8 张。保留用户当前“退出时清理缓存”关闭状态（与初次诊断不同），未改动此偏好。
- 返回桌面点击组件“切换下一篇”，依次验证 Sony Music Pro 和智界 R7 两篇文章，标题和配图对应，截图确认实际图片正常显示；切换后普通图片缓存仍只有 journal，证明使用了独立快照。组件 RemoteViews 的 bitmap memory 从初次诊断的 0 恢复为非零（其中一篇为 189440 字节）。
- 系统拒绝 shell 发送受保护的 APPWIDGET_UPDATE 广播，因此采用组件自身的切换按钮触发重载完成验证，未修改系统权限。
