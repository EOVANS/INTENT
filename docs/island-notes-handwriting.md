# 孤岛笔记手写功能开发文档

## 目标与范围

在现有文章段落笔记中添加可选手写内容，支持平板和手机手写笔快速记录。摘录和文字备注继续独立存在；没有手写的笔记、阅读器高亮、搜索和纯文字导出保持原有行为。首版不做手写识别、全文批注、云同步或笔迹转文字。

当前每段笔记由 `noBackupFilesDir/island-notes/<UTC 年月>/<UUID>.md` 保存，元数据在 Markdown 注释中，正文含摘录和备注。`NotesRepository` 以互斥锁与 `AtomicFile` 写入；`NotesScreen` 将笔记按文章合并后分享为单个 Markdown 文件。系统备份和普通缓存清理不包含笔记，卸载仍会删除本地数据。

## 交互与验收

1. 阅读器长按段落或点击已有高亮，打开现有备注编辑器；在文字框下提供“添加手写”或已有手写预览。未点击手写时不改变现有输入流程。
2. 手写使用全屏画布，支持固定粗细的彩色笔、笔画橡皮、撤销/重做、清空确认、完成及取消。画布尺寸限定在设备屏幕可视范围内，不支持滚动或延长新画布；保存后可预览并重新编辑。不提供粗细选择、压力变化或字迹识别。
3. 手指可切换为书写或擦除；画布本身不滚动。手掌误触不能仅依靠压力猜测：仅在明确识别笔输入后限制触摸绘制，并提供手动切换；验证设备对 stylus、eraser 和手掌事件的实际行为。
4. 保存同时保留摘录、文字和笔迹；取消画布编辑不改变已有笔迹，取消整个备注编辑不提交草稿。失败时保留当前草稿并显示重试。返回、旋转、进程终止场景不得静默覆盖已保存内容。
5. 手写可以为空或与文字共存。删除手写只移除笔迹；删除整条笔记才移除对应摘录、文字及手写。操作不可恢复时明确确认。
6. 列表显示手写标识或缩略图；搜索继续搜索原文字段，不声称手写可搜索。高对比度、深色模式、大字体、无障碍按钮名称和无手写笔设备均需可用。

## 数据格式与兼容性

- 增加可选的 `handwriting` 引用，旧 Markdown 不含此字段时行为不变；原始文字仍在 Markdown 中，不将其迁移到笔迹文件。
- 笔画放在同年月目录的受控附件目录，文件名由笔记 UUID 和不可预测的修订 ID 生成，禁止使用来自 Markdown 的任意路径。采用版本化 JSON，记录逻辑画布宽高、笔画顺序、颜色及坐标；旧笔画无颜色时默认为黑色，粗细固定。坐标相对画布而非设备像素，横竖屏和不同密度下按比例显示。校验有限数值、合法范围、文件大小和版本；不认识的版本保留文件并提示，不将其当成空画布覆盖。
- 一条笔迹保存为不可变修订：先用 `AtomicFile` 写完新修订并验证，再将同目录临时 Markdown 刷盘并原子替换目标，最后更新内存；失败时旧 Markdown 与旧修订保持可读。进程在任一阶段中断都不能使已提交 Markdown 指向半写文件。清理只针对确定未引用的旧修订，不能因为附件读取失败就清理；并发保存和删除在仓库同一把锁内执行。
- 手写预览是可重新生成的派生缓存，原始笔画才是唯一真实数据；预览损坏时可重建，不得因此删除笔迹。笔记删除先完成 Markdown 删除，再清理附件；清理失败保留安全孤儿并记录可恢复错误。
- 提供可恢复的草稿存储，按笔记或新建段落身份独立保存，不放进 saved-instance-state；仅在用户完成或明确丢弃后清理。避免大型笔画序列进入 Bundle。对草稿保存使用节流和后台 IO，退出时等待最后一次写入；存储不足应保留已提交版本并提示。

## 导出与隐私

- 纯文字笔记继续分享 Markdown。选择内容包含手写时，分享 ZIP：Markdown、由笔画生成的 PNG 和可编辑笔画 JSON，以相对路径引用预览；文件名和路径安全，导出快照在锁内取得一致引用。不要把包含手写的笔记静默导出为缺少笔迹的 Markdown。
- ZIP 是分享格式，不等同可恢复备份；在有完整导入及校验之前不得宣称可通过它恢复 App 内的可编辑笔记。原有无云备份说明须增加手写提示。临时分享文件只在缓存中生成，通过 FileProvider 授权，清理策略不影响原文件。
- 笔迹、预览、草稿和文字均只在本机处理；不提交给 AI、网络服务或系统云备份。搜索和日志不包含笔画内容。

## 工程拆分

1. 定义版本化笔画模型和严格校验，保持旧 Markdown 往返及未知字段兼容；补充有效、损坏、超限和旧文件测试。
2. 实现附件仓库、原子提交与删除、草稿恢复，注入失败测试覆盖每个提交阶段和并发操作。
3. 实现固定粗细笔输入、手指模式、撤销/重做、擦除和预览；将画布编辑状态与文字草稿分离，再接入阅读器和笔记详情两个入口。
4. 实现包含手写的 ZIP 分享与纯文字兼容；补充四种界面语言和无障碍语义。
5. 真机验证后再启用入口。每阶段单独提交，保证可回滚；未完成持久化和导出前不对用户暴露手写入口。

## 当前实现与限制

- 手写工具栏依次为笔、橡皮、手指模式、重做、撤销、清空、背景色；返回和完成固定在两侧。笔色浮层点击笔打开，实际落笔后收起且不改变画布位置。手指模式切换后显示用途说明。
- 手写窗口隐藏状态栏，书写期间移除底层笔记弹窗，避免摘录文字叠在画布中间；原文仅在弹窗和详情展示。背景提供调色盘预设色，保存于 `backgroundColor`，旧文件默认为白色；草稿、预览和 PNG 导出均使用同一背景色。
- 无文字备注但有手写的笔记卡片显示“包含手笔速写”；详情直接展示手写。段落弹窗的手写入口靠右，弹窗和详情预览均完整缩放、居中并使用圆角。
- 阅读器段落和笔记详情可打开手写编辑器；提供彩色笔画、手指书写开关、调色盘背景色、按笔画擦除、撤销/重做、清空确认和预览。
- 每次修改后约 500 毫秒将文字及已完成笔画写为独立草稿；重新打开同段会恢复。保存时文字和笔迹通过同一次 Markdown 引用提交。进程在延迟窗口内终止时，最后一次尚未写入的修改可能丢失。
- 纯文字继续分享 Markdown，包含手写时分享 ZIP（Markdown、PNG 和笔画 JSON）。ZIP 当前不可导入恢复。
- 平板上通过手指模式确认画布可绘制并可取消；真实手写笔、防误触、手写笔延迟和 Galaxy S Ultra 尚需真机验证。并非所有触控笔都能被系统识别为手写笔，无法识别时需手动开启手指书写。

## 验证清单

- 回归：旧笔记加载/编辑/搜索/删除、同段去重、文章排序、文字 Markdown 分享和缓存清理保持不变。
- 数据：空笔画、多笔画、跨尺寸显示；错误版本、损坏内容、非法路径、超大文件和磁盘写入失败；保存中止、重启、并发保存/删除与附件孤儿处理。
- 操作：手写笔、手指模式、手掌接触、橡皮、撤销/重做、取消/恢复、清空、旋转、后台回收、键盘与画布切换；文字和手写混合保存与重新打开。
- 导出：仅文字 `.md` 与含笔迹 ZIP 的内容、预览和相对引用；选择取消、分享目标不可用与磁盘不足不改变原笔记。
- 设备：连接的平板竖屏/横屏、支持 S Pen 的 Galaxy S Ultra、无笔手机；浅色/深色、大字体和 TalkBack。性能记录首笔延迟、连续书写掉帧及大量笔画打开时间；目标与测量设备在测试记录中明确，不能凭模拟器推断手感。
